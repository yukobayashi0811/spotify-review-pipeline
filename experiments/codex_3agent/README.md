# Codex three-worker development experiment

This folder contains development-only experiments. Its outputs are not grading exports and do not replace the saved program, the assignment's formal model-call evidence, the required 100-review cold/warm run, or full-corpus execution.

The harness uses ChatGPT-subscription authentication through a pinned Codex CLI, not an API key. Monetary incremental cost is therefore recorded as `unknown`, even when token counters are available. Golden labels are never supplied to the workers.

The stop line for this run is 73% account-wide usage. The snapshot can move because of other Codex work, so any observed delta is not attributed exclusively to the experiment.
