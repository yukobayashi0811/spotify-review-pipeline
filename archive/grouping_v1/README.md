# Grouping v1 archive

This directory is a read-only snapshot of the pre-rebuild grouping, ranking,
memo, and grading export. It was captured before the embedding-based grouping
work started on 2026-10-03 (America/Los_Angeles).

- `artifacts/full_run_v2/`: prior grouping, ranking, memo, and claim artifacts
- `grading/`: prior grading export
- `root/memo.md`: prior repository-root memo
- `SHA256SUMS`: checksums computed at capture time (before this README existed)

The full classification state, prompts, label configuration, and classifier
artifacts were intentionally not modified or copied into this archive.
