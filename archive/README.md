The scripts were written for the original folder layout and are kept for reading, not to be run from here. |
| `grouping_v1/` | The TF-IDF grouping that the embedding grouping replaced in the earlier run. |
| `frozen_100_failed_pre_code_owned_claims/`, `frozen_100_failed_pre_surface_repair/` | Failed 100-review proof attempts from the earlier run, each named after the fix that followed it. |
| `pre_audit_2026-10-06/`, `pre_claude_2026-10-07/` | Snapshots of files replaced during reviews of the earlier run. |
