# Golden-set workflow

## Human Golden 50

`golden_50.csv` is the 50-review human gold set. Every label (topic, intent, sentiment, severity, entities, evidence_quote) was assigned by hand from the review text, following `config/labels.md`, in the labeling workbook `golden_50_labeling_completed.xlsx`. No model prediction or AI-generated label was viewed or used. Provenance and file hashes are in `golden_50.provenance.json`.

`golden_50_to_label.csv` is the selection file and `golden_50_labeling.xlsx` the blank labeling template.

## Leakage-safe scoring

The model receives only `artifacts/golden_prediction_input.csv`. Its manifest proves that no label fields were copied. Training code excludes all Golden review IDs, exact-text SHA-256 values, and NFKC/casefold/whitespace-normalized text SHA-256 values before fitting or threshold selection.

Predictions must be saved before `golden_50.csv` is opened for scoring:

```sh
spotify-pipeline golden-export-predictions \
  --state artifacts/runtime/golden.db \
  --output evals/golden_predictions.csv

spotify-pipeline golden-score \
  --golden evals/golden_50.csv \
  --predictions evals/golden_predictions.csv \
  --output evals/evaluation.json \
  --cases evals/evaluation_cases.csv
```

Every saved Golden prediction file in the repository, and the final full-corpus labels of the 50 Golden reviews, can be scored again with zero model calls:

```sh
PYTHONPATH=src python3 scripts/rescore_golden.py
```

## Final classifications (Golden 50)

`golden_final_evaluation.json` scores the final labels of the 50 Golden reviews taken from the grading export of the final run (`golden_final_predictions.csv`). The Golden texts were part of the full-corpus run; their labels were never model inputs.

| Metric | All 50 | Local classifier (48) | GPT-6 Luna (2) |
|---|---:|---:|---:|
| Topic agreement | 82% | 83.3% | 1 of 2 |
| Intent agreement | 80% | 81.3% | 1 of 2 |
| Exact severity agreement | 64% | 64.6% | 1 of 2 |
| Severity within ±1 | 92% | 93.8% | 1 of 2 |
| Severity MAE | 0.46 | | |
| Sentiment MAE | 0.29 | | |
| Entities exact match | 48% | | |
| Evidence quote is an exact source substring | 100% | | |
| Macro-F1 topic / intent / severity | 0.775 / 0.632 / 0.489 | | |

Only two Golden reviews were routed to GPT-6 Luna in the final run, too few for a separate accuracy claim. Most severity disagreements are one point: the final labels give 3 where the human label is 4 (blocked playback or song selection) and 2 where the human label is 1 (generic criticism with no reported functional problem). Evidence quotes: all 50 are exact substrings (checked in code); read against the predicted label, the quote supports it in 41, partly in 5 and not in 4, and in those 4 the label rather than the quote is wrong (`quote_supports_label` column). No predicted entity is absent from its review. Every disagreement is categorized in `golden_final_error_analysis.md` (generated by `scripts/golden_error_analysis.py`; per-case rows in `golden_final_error_cases.csv`).

## Fresh held-out 30

Because the Golden 50 influenced one earlier design decision (see `experiments/distilled/README.md`), a fresh set was labeled after the final configuration was fixed:

- Sampling: a seeded random 60 reviews excluding the Golden 50 and `checkpoint_500` (`holdout_60_sampling_manifest.json`); the first 30 by `review_id` were labeled (`holdout_30_to_label.csv`).
- Labeling: by the author, from the review text only, with no prediction shown, following `config/labels.md` (dropdowns restricted to the label values). The labeling sheet export is `holdout_30_labels_sheet_export.csv`; `scripts/score_holdout.py` converts it to `holdout_30.csv` (same columns as `golden_50.csv`). These labels were never model inputs and never used for tuning.
- Scoring: the same scorer as the Golden 50, against the final run's labels (`holdout_30_predictions.csv`).

| Metric | Held-out 30 |
|---|---:|
| Topic agreement | 63.3% |
| Intent agreement | 83.3% |
| Exact severity agreement | 40.0% |
| Severity within ±1 | 76.7% |
| Severity MAE | 0.83 |
| Sentiment MAE | 0.33 |
| Entities exact match | 56.7% |
| Evidence quote is an exact source substring | 100% |
| Macro-F1 topic / intent / severity | 0.503 / 0.671 / 0.236 |

29 of the 30 reviews carry local-classifier labels and one a GPT-6 Luna label, so this mainly measures the local classifier. Results are lower than on the Golden 50, especially for topic and severity; with 30 reviews, one review moves a rate by 3.3 points. Two reviews were labeled `unclear` by the labeler. Details: `holdout_30_evaluation.json`, per-case `holdout_30_evaluation_cases.csv`.

```sh
python3 scripts/score_holdout.py --labels evals/holdout_30_labels_sheet_export.csv
```

## needs_review as a prediction

`golden_needs_review_analysis.json` evaluates each model's `needs_review` flag as a prediction of its own label errors (topic, intent or exact severity differing from the human label). For the final labels, the flag was set on 16 of the 50 Golden reviews: 75% of flagged rows had a label error, against 38% of unflagged rows, and the flag caught 12 of the 25 rows with an error. The flag is therefore a useful review queue but misses about half of the errors. Three Golden reviews carry the human intent label `unclear` (no complaint, request, praise or departure supported by the text); they are counted as the ambiguous cases.
